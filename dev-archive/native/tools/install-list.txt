# What build.sh --deploy puts in the RE2 folder, layer by layer (the clean rebuild, 2026-11-07).
# One line: <layer> [max=N] <source> <game path>
#   layer   the line goes in when --layer is this number or higher (max=N: and only up to layer N)
#   source  repo:<path under dev-archive/native/>   or   backup:<path under the backup's game/ folder>
#           backup: = files that never go on GitHub (other people's binaries, our generated game-format files)
#   a source that is a folder is copied whole
# Everything of OURS in the game folder that is not on the list for the chosen layer is moved out by --deploy.
