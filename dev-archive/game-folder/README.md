# Files that go straight into the game's main folder

- `_interaction_profiles_oculus_touch_controller.json` (2026-10-11): REFramework's OpenXR controller bindings for
  Touch controllers, taken unchanged from Arcade Controls for RE2 VR 1.2.0. The D-pad (REFramework's
  `weapondial_start`) is held on the RIGHT STICK CLICK, with the left stick choosing up/down/left/right; the left
  trigger is a plain trigger and no longer the D-pad. Tefa asked for it so LT is free for the flashlight.
