# A different ammo type on each hip

Order: 8001
From: the ideas repo, `games/resident-evil-all.md` (<https://github.com/TefMeister/mod-ideas/blob/main/games/resident-evil-all.md>), copied 2026-11-01

`[raw]` · `[not judged]` — *not checked against any RE game yet*

**What Tefa said (2026-11-01):** for every RE gun that has more than one ammo type in the game (the grenade launchers'
acid / flame / explosive rounds, the shotguns' and others' where they exist), put one type in the pouch on each hip, so
the hand you reach with chooses the round. Tefa wants this idea worked through to the end ("exhaust the idea").
